## Project Overview

Club Sport Goodwill (CSG) is a concept-based supercar charity
organisation that brings together supercar owners, enthusiasts,
supporters and charitable causes.

The organisation uses the excitement and passion surrounding
high-performance and luxury vehicles to encourage charitable
contributions and community participation.

CSG will host exclusive supercar events where vehicle owners can
showcase their cars while enthusiasts and supporters contribute
towards selected charitable causes.

The website provides information about CSG, upcoming events,
donation opportunities, vehicle-owner participation and ways for
supporters to become involved.

The website aims to balance a premium automotive aesthetic with
the trust, accessibility and transparency expected from a
charitable organisation.

---

## Website Goals and Objectives

The primary goals of the website are:

- Promote Club Sport Goodwill and its charitable purpose.
- Promote upcoming supercar events.
- Encourage charitable donations.
- Connect supercar owners with enthusiasts.
- Provide information about donation levels and benefits.
- Allow vehicle owners to express interest in showcasing their cars.
- Increase event participation.
- Attract potential sponsors and partners.
- Build an online automotive community.
- Communicate fundraising and charitable information transparently.

## Design Concept

The website uses a premium automotive visual style.

The main design characteristics include:

- Dark backgrounds.
- Racing Red accents.
- High-quality supercar photography.
- Bold typography.
- Minimal and modern layouts.
- Strong calls-to-action.
- Responsive layouts for mobile devices.
- Event poster
- Google Maps event location

The visual identity is designed to communicate luxury and performance
while maintaining a professional charitable image.

# Conclusion

The development and improvements made to the ClubSport Group website have transformed it into a more professional, attractive and user-friendly platform.

Previously, the website lacked sufficient content, such as images, and required improvements to its overall styling, layout and presentation. The addition of images, improved navigation, updated typography, consistent CSS styling and Google Maps integration helped address these limitations.

The website now communicates the ClubSport Group's automotive identity more effectively while providing visitors with a clearer and more engaging browsing experience.

Further improvements can include adding interactive features, enhancing mobile responsiveness and implementing additional functionality to improve visitor engagement.
